# JBK Estates

Website rebuild for JBK Estates Ltd, a UK property development and building company. Work covers extensions, conversions, house refurbishments, kitchens and bathrooms, general building works, and new builds.

Stack: Astro, TypeScript, Tailwind CSS v4 (`@tailwindcss/vite`), `@astrojs/sitemap`. No UI framework. Contact form posts to Web3Forms.

This is a scaffold. Real photography, copy and contact details will replace the placeholders.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

The dev server runs at [http://localhost:4323](http://localhost:4323).

Add `PUBLIC_WEB3FORMS_KEY` in `.env` to enable the contact form.

## Pages

- `/` Home
- `/services` Extensions, conversions, refurbishments, kitchens & bathrooms, general building, new builds
- `/gallery` Project photography (placeholders)
- `/about`
- `/contact`
- `/privacy-policy`
- `/legal-notice`
